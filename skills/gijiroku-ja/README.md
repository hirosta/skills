# gijiroku-ja

日本の会社の1回の打ち合わせについて、渡されたメモ・文字起こしの文章から日本語の議事録を作るスキルです。決定事項、宿題、持ち帰り、持ち越しを分け、社外の参加者がいる場合は内容確認のお願いのメールも下書きします。

録音の文字起こしはしません。カレンダー・メール・タスク管理のサービスには接続せず、配布・送信・予約もしません。ファイルや設定を確認なしに変更する手順は含めません。

## 決まり

| 項目 | 扱い |
| --- | --- |
| 決定 | 「〜とする」「〜で進める」と合意したものだけを載せる |
| 持ち帰り | 検討・社内確認は採用の決定にせず、担当と回答期限を付ける |
| 宿題 | 担当と実施期限を付け、欠落は「要確認（担当）」「要確認（期限）」とする |
| 持ち越し | 未決の理由と次回の議題案を残し、分類できない発言も要確認として残す |
| 期限 | 会議日を基準に西暦の日付と曜日を書く。「来週中」などの具体日を作らない |
| 文体と敬称 | 議事録は常体。社外は会社名と「様」、社内は指定に合わせた役職か「さん」 |
| 記録の種類 | 利用者が発言録・要点録を選び、指定なしは要点録 |
| 編集 | フィラー・言い直しの重複を除く。数字・固有名詞・金額・日付を変えない |
| 配布前 | 確認役が原文と配布範囲を確認する。不明な社外秘は「配る前に確かめる」と表示する |

理由は [minutes-rules.md](references/minutes-rules.md)、型と点検の入力仕様は [templates.md](references/templates.md) を参照してください。

## 入れ方

AIエージェントのスキル用フォルダーへ `skills/gijiroku-ja/` をフォルダーごとコピーします。`LICENSE` も含めてください。同名のフォルダーがある場合は、内容を確認して上書きするか決めてからコピーします。他のスキルは必須ではありません。

点検にはPython 3.9以上を使います。Pythonの標準ライブラリだけで動き、依存の追加は不要です。

## 使い方

```text
gijiroku-jaで、この架空の文字起こしを議事録にしてください。
会議名は「架空・こもれび企画の資料定例」、日付は2026-11-03です。
参加者は全員社内、要点録、敬称は「さん」にしてください。
文字起こしと、確認済みの人名の別表記を続けて渡します。
決定と宿題の一覧を先に見せ、本文は会話内に返してください。
```

名前・日付・参加者・材料の足りない部分だけを最大3問で確認し、残りは「要確認」として進めます。材料がなければ記入用の型だけを返します。社外の参加者がいれば確認メールの草稿も返します。確認期限・宛先・確認役が不明でも作りません。

点検はリポジトリのルートから、既存の議事録を指定して実行できます。

```bash
python3 skills/gijiroku-ja/scripts/check_minutes.py skills/gijiroku-ja/examples/01-before.md
python3 skills/gijiroku-ja/scripts/check_minutes.py skills/gijiroku-ja/examples/01-after.md
```

入力はUTF-8の定型Markdownです。4分類の見出しと、宿題・持ち帰りのパイプ表（または「なし」）が必要です。自由形式の文章をそのまま渡すと入力エラーになることがあります。人名の点検は、参加者表に同一人物と確認済みの「表記」「別表記」を登録した場合だけ行います。姓や役職からの推測はしません。

検出があっても終了値0、引数・入力の誤りは2です。出力は行番号と検出項目、合計、最後に人が確かめる点です。エラーも標準出力に表示し、入力の文章やパスは再掲しません。指定ファイルの読み取りと標準出力だけを行い、ファイルの作成・変更やネットワーク接続はしません。会話の草稿を点検用に保存する場合は、利用者に内容と保存先を確認してから行います。

## 架空の素材と試した結果

条件：GPT-6（Codex）が架空の文字起こし3本、意図的な誤りを含む修正前3本と、決まりに沿った修正後3本を作成しました。同じモデルがスクリプトを6本に実行し、原文と出力を手動で照合しました。修正前は検証用に作った例で、実際のAI利用から集めた失敗例ではありません。会社・人物・案件・金額・発言はすべて架空です。実在の会議の内容は使っていません。

### 機械点検

件数は検出項目の一致数で、議事録の評価点ではありません。同じセルで「期限の抜け」「残った要確認」などが重なります。情報が未確定のままなら修正後も表示を残します。

| 架空の文字起こし | 修正前 | 修正後 | 修正後に残った表示 |
| --- | --- | --- | --- |
| [01 社内定例](examples/01-transcript.md) | [10件](examples/01-before.md) | [3件](examples/01-after.md) | 期限の抜け1、あいまいな期限1、要確認1。「来週中」の具体日が未提供 |
| [02 社外会議](examples/02-transcript.md) | [8件](examples/02-before.md) | [0件](examples/02-after.md) | なし。ただし社外秘区分の未確認は人が確認する必要がある |
| [03 未決が多い会議](examples/03-transcript.md) | [11件](examples/03-before.md) | [6件](examples/03-after.md) | 担当の抜け1、期限の抜け2、要確認3。材料にない情報は補っていない |
| 合計（各3本） | 29件 | 9件 | 未確定の情報を残した結果であり、品質改善の測定ではない |

### 決定と持ち帰りの手動照合

次の表の表現数は、各文字起こしに意図的に入れた発言の数です。各表現を原文と修正前後の分類欄で照合しました。「検討します」「持ち帰ります」だけでなく「社内で確認します」も別列で示します。

| 例 | 「検討します」/「持ち帰ります」の数 | 「社内で確認します」の数 | 決定欄に残った対象表現（前→後） | 修正後の分類と手動確認 |
| --- | --- | --- | --- | --- |
| 01 | 1 / 1 | 0 | 2→0 | 決定1件、持ち帰り2件。案甲の合意と案乙・追加図の回答待ちを分離 |
| 02 | 0 / 0 | 1 | 1→0 | 決定1件、持ち帰り1件。展示台の合意と照明の社内確認を分離 |
| 03 | 1 / 1 | 0 | 2→0 | 決定0件、持ち帰り2件。案丁・寸法とも採用を決めていない |

03の修正前にある「用紙の案戊とする」は、原文に合意がない誤った決定です。対象表現に一致しないためスクリプトは検出しませんでしたが、手動照合で持ち越しへ直しました。印刷費の2つの金額も片方に決めず両方を残しました。これは機械点検だけで正しさを判断できない例です。

02は発言録と [確認メールの草稿](examples/02-email.md) を用意し、話者・金額・敬称、件名の会議名と日付、確認期限、返信での修正方法を手動照合しました。原価の内訳の配布可否を保留し、メールに内訳を転載していません。利用者との確認の往復、実際の配布・送信は試していません。

### 実装の確認

同梱の議事録6本は検出の有無にかかわらず終了値0でした。追加の架空素材で日付・曜日、期限の形式、欠落列、複数人に対応する別表記の衝突を手動確認し、空入力・文字コードの誤り・必須見出しの欠落・表の列数の不一致・引数の誤りは終了値2、ヘルプは0を確認しました。構文と字下げ、標準ライブラリだけのインポート、リンクと差分の空白を点検しました。自動テスト・テストスイートは作成していません。

構文はASTとコンパイル、字下げは標準ライブラリの `tabnanny` で確認しました。ruffは未導入のため未実行です。スキル共通検証ツールは追加依存のPyYAMLがなく実行できなかったため、frontmatter・命名・参照先を直接点検しました。追加依存は導入していません。

## 分かっていないこと・範囲外

- 実際の文字起こしの崩れ、長い会議、複数の話者の取り違えは未検証です。録音からの文字起こしはしません。
- 業種・会社ごとの議事録の慣習、役職や敬称の適合は未検証です。確認役が利用者の指定と原文を照合します。
- 日付と曜日の形式や定型表は点検できますが、否定・引用・条件付き合意、未登録の人名のゆれ、未知のフィラーは見逃しや過剰検出があります。祝日・営業日の計算や自由形式の表の読み取りはしません。
- 検出0件でも決定の正しさ・社外秘の扱い・敬語の適切さを保証しません。02のように機密区分が未確認でも0件になり得ます。配布前の人の確認が必要です。
- 作成時間や伝達の効果、独立したモデル・人による品質評価、確認依頼への応答は測定していません。効果は保証しません。

## internal-notice-jaとの線引き

`gijiroku-ja` は1回の打ち合わせの記録と、その内容確認のお願いだけを扱います。会議の結果を全社に知らせる文面は、同じスキル集の `internal-notice-ja` に任せます。
