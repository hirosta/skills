# task-brief-check-ja

開発、資料づくり、調査、データ整理をAIエージェントに任せる前に、日本語の依頼文を点検するスキルです。足りない点（×）、気になる点（△）、利用者が決めること、書き直し案を返します。

AIのエージェントに作業を任せる運用で使ってきた点検の項目を、一般向けにまとめたものです。

## 点検すること

- 目的、やること・やらないこと、対象と作業の完了を確かめる条件
- 前提となる値・日付・名前と、会話を知らない読み手にも分かる表現
- 主語・目的語の省略や「適宜」「など」から生じる曖昧さ、前置きの長さ
- 送信、公開、本番反映、削除、支払い、外部サービスへの登録を誰がどこまで行うか
- パスワード・APIキー・個人情報の候補。値を伏せ、別の渡し方を案内
- 利用者が指定した書式と実際の行の違い

項目ごとの理由は [点検の決まり](references/rules.md)、依頼の種類に応じた完了条件は [受け入れ条件の例](references/kinds.md) にあります。

## 入れ方

利用するAIエージェントのスキル用フォルダーへ `skills/task-brief-check-ja/` をコピーします。同名のフォルダーがある場合は内容を確認してからコピーしてください。補助スクリプトはPython 3.9以上の標準ライブラリで動きます。

## 使い方

`task-brief-check-jaで、次の依頼文を渡す前に点検してください。` と伝え、日本語の依頼文を1本または複数本渡します。文章を貼り付けるか、UTF-8のファイルを指定できます。書式も点検したいときは、依頼文と別に書式一覧を渡してください。

機械点検だけを試す場合は、リポジトリのルートで次を実行します。

```bash
python3 skills/task-brief-check-ja/scripts/check_brief.py \
  skills/task-brief-check-ja/examples/research-before.txt \
  skills/task-brief-check-ja/examples/research-after.txt \
  --format-list skills/task-brief-check-ja/examples/research-format.txt
```

- 1ファイルが1本です。複数ファイルを渡すと入力順に番号を付けて表示します。
- 機械点検では「目的」「範囲」「やらないこと」「受け入れ条件」と代表的な別名を探します。`目的：内容` のような項目や、直下に本文がある `## 目的` のような見出しに対応します。
- 書式一覧は任意です。UTF-8で、`項目名：値の形` を1行に1件書きます。`YYYY-MM-DD` は実在する暦日を指定する箇所に使い、ほかの部分は文字どおりに照合します。対応する項目の行があれば、余分な説明やコロン・空白の違いを表示します。項目自体が見当たらない場合の確認は目視で行います。
- ×・△が1件以上あれば終了値1、0件なら0です。引数・入力エラーは2です。「参考」の行は、操作の許可・禁止・人の確認を示す記載の候補です。
- スクリプトは指定ファイルを読み、結果を標準出力に表示します。AIエージェントは機械の候補と原文を照合し、会話内に報告と文案を返します。外部サービスへの接続、依頼の送信・起票、元のファイルの変更は範囲外です。

## 試した結果

条件は同梱の架空の依頼文4組（修正前4本、修正後4本）です。GPT-6（Codex）が例を作成し、スクリプトの出力と終了値を手動で照合しました。機械点検自体はPythonで実行しました。調査の2本にだけ同梱の書式一覧を指定しました。

| 種類 | 修正前 | 修正後 | 出力件数（× / △） | 終了値 |
| --- | --- | --- | --- | --- |
| 開発 | [修正前](examples/development-before.txt) | [修正後](examples/development-after.txt) | 4 / 3 → 0 / 0 | 1 → 0 |
| 資料づくり | [修正前](examples/document-before.txt) | [修正後](examples/document-after.txt) | 4 / 3 → 0 / 0 | 1 → 0 |
| 調査 | [修正前](examples/research-before.txt) | [修正後](examples/research-after.txt) | 1 / 3 → 0 / 0 | 1 → 0 |
| データの整理 | [修正前](examples/data-before.txt) | [修正後](examples/data-after.txt) | 3 / 3 → 0 / 0 | 1 → 0 |

件数は検出項目の一致数です。依頼文の良し悪しの点数には使えません。同じ行に同じ種類の曖昧な語が複数あっても、その種類は1件として数え、見つかった語を「」で囲んで並べます。秘密の情報の候補は、値を写さないよう行番号だけを表示します。

## 分かっていないこと・範囲外

- 見出しのない文章や、言い換えの多い文章では機械点検に見落としや過剰な指摘が生じます。敬語や方言の多い文での誤検出・見落としは検証していません。
- 秘密の情報と取り消しにくい操作は、既知の表記や近接する語から候補を出します。値の検出、操作ごとの権限と対象、複数行にわたる指示は原文も確認してください。入力を共有するときは、先に秘密の値を伏せてください。
- 目的と完了条件の適切さ、数値・日付・名前が作業に足りるか、主語・目的語や前置きの問題は文脈を読んで判断します。作業前の聞き返し件数、作業の成功率、手戻りへの影響は測っていません。
