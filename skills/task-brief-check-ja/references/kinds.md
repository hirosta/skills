# 種類ごとの受け入れ条件

分類は主な成果物で決める。以下はすべて架空の作業。件数・日付・名前は実際の依頼の条件で置き換える。

| 種類 | 条件の書き方 | 例 |
| --- | --- | --- |
| 開発 | 操作、入力、期待する表示や結果をセットにする。 | 在庫一覧で「在庫なし」を選ぶと、在庫数0の棚だけが表示される。「すべて」に戻すと全件表示に戻る。 |
| 資料づくり | 形式、分量、掲載必須の項目を挙げる。 | 備品貸出の説明をMarkdown 1ページにまとめる。貸出、延長、返却の各手順を1節ずつ掲載する。 |
| 調査 | 比較対象、基準日、確認項目、根拠の残し方を指定する。 | 配布された資料2件について、常温保管日数と開封後の注意点を表にする。各セルに資料名とページを添え、資料に記載がなければ「記載なし」とする。 |
| データの整理 | 入出力、変換規則、件数や例外の照合方法を決める。 | 受付データ12件を受付番号で整列し、新しいCSVに出す。入力と出力のデータ行がともに12件で、重複行を一覧で確認できる。 |
| その他 | 人が確かめられる成果物を指定し、判断や実行の担当を示す。 | 鍵の受け渡しの案内文に場所・受取時間・連絡窓口を含める。文案の宛先と内容は担当者が確認する。 |
