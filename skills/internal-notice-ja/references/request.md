# 部署内の依頼・連絡

共通の決まりに加え、以下を使う。

## 型（見出しの順番）

だれに・何を・いつまで → 入力条件や手順 → 返信要否と返信先 → 問い合わせ先。依頼は1行目に置く。

## 書く量の目安

本文4〜8行程度。複数の担当や期限があるなら対応表を使い、不要な挨拶を増やさない。量のために材料を削ったり、情報を足したりしない。

## 架空の例

会社、部署、規程、数字、日時、出来事はすべて架空。

```text
件名：【ご依頼】貸出一覧の未返却欄更新・2026年11月6日（金）15:00期限
管理部の備品担当者は、2026年11月6日（金）15:00までに貸出一覧の未返却欄を更新してください。
未返却がない場合も「なし」と入力してください。
更新後は管理部窓口へ完了を返信してください。

問い合わせ先：管理部窓口
```

## よくある失敗

「各自対応」で担当をぼかす。「なるべく早く」で締切を済ませる。完了連絡の要否や未該当時の入力を省く。
