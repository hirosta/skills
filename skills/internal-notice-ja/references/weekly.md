# 週報・進捗の報告

共通の決まりに加え、以下を使う。

## 型（見出しの順番）

予定に対する結論と相談 → 進んだこと → 困っていること・相談 → 来週の予定 → 問い合わせ先。冒頭には来週の要約も置いてよい。

## 書く量の目安

本文8〜15行程度。数字は今週の増分と累計を分け、対象・単位・比較期間をそろえる。前週値がなければ要確認とし、計算で補える値も材料と照合する。量のために材料を削ったり、情報を足したりしない。

## 架空の例

会社、部署、規程、数字、日時、出来事はすべて架空。

```text
件名：【報告】備品台帳整備の週報・2026年11月2日（月）〜2026年11月6日（金）
2026年11月6日（金）17:00時点で、今週予定20件のうち18件が完了し、2件遅れています。
上長は未完了2件の分類方針を2026年11月9日（月）12:00までに判断し、この週報へ返信をお願いします。
来週は未完了2件を先に処理します。

進んだこと：今週完了18件。累計完了は前週12件 → 今週30件です（同じ備品台帳の対象レコード数）。
困っていること・相談：2件は分類の判断待ちです。上記の方針の判断をお願いします。
来週の予定：分類方針の回答を受け、未完了2件から処理します。
問い合わせ先：台帳整備担当
```

## よくある失敗

活動一覧で始めて遅れを隠す。今週分と前週累計を直接比較する。相談を「ご認識ください」で済ませる。
