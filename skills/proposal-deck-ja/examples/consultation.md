# 架空の相談メモ

これは実在の会社・人物・案件と関係のない演習用素材です。

- 提案先：しらかば物産株式会社（架空）
- 件名：受注記録の共通化案
- 提案日：2026年10月24日（架空）
- 相談内容：メールと電話で受注を受ける。メールは担当者が内容を確認し台帳へ転記する。電話は手元にメモし、確認後に台帳へ転記する。担当者によって確認項目が違う
- 提案すること：必須項目と記録先をそろえ、記入漏れ・差し戻しを試行で記録する。台帳への自動記録は連携条件を確認してから判断する
- 期間：4週間。初週に対象確定、2週目に手順整理と連携確認、3週目に試行、4週目に評価
- 概算予算：80万円（税別）。項目・手順整理30万円、連携確認・試行支援50万円。追加開発・運用保守・本稼働は対象外
- 提案側：みなも企画株式会社（架空）。体制案は提案窓口と業務整理担当。連絡先の仮置きは proposal@example.com
