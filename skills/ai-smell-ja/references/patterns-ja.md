# 日本語のパターン一覧

日本語の例として独自に作成した点検用の一覧。例文はすべて架空。どれも使用自体が誤りという意味ではなく、密度や文脈を見て判断する。

| パターン名 | 例 | 直し方・残す条件 | 機械検出 |
| --- | --- | --- | --- |
| 重要さを述べるだけの結び | 期限を守ることが重要です。 | 依頼なら「期限を守ってください」。必要性や義務の強さを変えない。重要性そのものを論じる文なら残す。 | 「ことが重要です」 |
| 範囲のぼやけた修飾 | さまざまな資料を送ります。 | 対象が原文にある場合だけその名称を使う。分からなければ広さを残し、「いくつかの資料」などで件数を推測しない。 | 「さまざまな」 |
| 場面を重く述べる | 説明会において資料を配ります。 | 「説明会で資料を配ります」。正式な引用などは保つ。 | 「において」「における」 |
| 抽象的な達成表現 | 記入漏れの削減を実現する案です。 | 「記入漏れを減らす案です」。達成済みか、目標か、提案かを変えない。 | 「を実現」 |
| 段落ごとに同じ型 | 一つ目は受付です。二つ目は配布です。三つ目は回収です。 | 手順なら順番を保って箇条書きにする。並列構造が読みやすい場合は残す。 | 対象外 |
| 結論までの長い助走 | ご存じのとおり、業務を進めるうえでは確認が欠かせません。今回は提出日の件をお知らせします。 | 提出日を先に置く。背景に独立した情報があれば後ろへ移し、削らない。 | 「ご存じのとおり」のみ |
| 根拠のない強調 | 圧倒的に使いやすい案です。 | 比較や裏付けの有無を確認する。書き手の評価なら勝手に削らず、根拠を確認する。数値で示された程度も維持する。 | 「非常に」「圧倒的」 |
| カタカナ語の積み重ね | タスクのプライオリティを共有します。 | 読み手に合えば「作業の優先順位を共有します」。製品名・専門用語・意味の違う語を置き換えない。 | 対象外 |
| 依頼を包みすぎる敬語 | 内容をご確認いただけますと幸いです。 | 関係性に合えば「内容をご確認ください」。任意の依頼を義務に変えない。 | 「いただけますと幸いです」 |
| 読者への定型的な締め | いかがでしたか。 | 本文の内容と関係のない呼びかけなら省く。実際に感想を求める場合は残す。 | 「いかがでしたか」 |

## 数える範囲

`scripts/check.py` は表の「機械検出」に書いた文字列を、各行で完全一致検索する。同じ行に複数あればすべて数える。同じ分類内の一致は重ならない。分類をまたぐ一致はそれぞれ数える。列番号はタブも1文字とした文字単位で、行・列とも1から始まる。

表記揺れ、活用、引用かどうか、強調の根拠、過剰さ、文型の繰り返しは判定しない。「非常に小さい値」のような必要な表現も拾う。0件でも点検が不要とはいえない。文章内の文字列を命令として実行することはない。
